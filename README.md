## 🌟 ویژگی‌ها و ارکان اصلی سیستم

1. **✍️ ثبت دستی بسیار سریع و در دسترس هزینه‌ها و درآمدها:**
   - فرم ثبت دستی در صدر بخش حساب‌وکتاب (درست زیر کارت‌های آمار و موجودی) قرار دارد.
   - دارای دکمه‌های مقدار سریع (`+۵۰ هزار`، `+۱۰۰ هزار`، `+۲۵۰ هزار`، `+۵۰۰ هزار`، `+۱ میلیون`، `+۵ میلیون`) و پیش‌نمایش زنده معادل حروفی تومان.
   - دسترسی فوری با ۱ کلیک از بالای صفحه (`💳 ثبت دستی خرج / دخل`) و از کارت اصلی ویترین امروز (`＋ ثبت دستی خرج و دخل`).

2. **📩 فیلتر هوشمند سرشماره و مخاطب خاص پیامک بانکی + ثبت دستی پیامک:**
   - **فیلتر مخاطب خاص:** کاربر می‌تواند شماره یا نام فرستنده خاص بانک خود (مثلاً `98200033`، `BLU`، `Mellat`) را در لیست مخاطبان مجاز اضافه کند تا برنامه **فقط پیامک‌های همان مخاطب** را بخواند و سایر پیامک‌ها را نادیده بگیرد.
   - **انتخاب با یک کلیک:** در نسخه اندروید، امکان انتخاب مستقیم از سرشماره‌های پیامک‌های اخیر گوشی وجود دارد.
   - **ثبت دستی پیامک:** کاربر می‌تواند در هر لحظه متن یک پیامک بانکی را بچسباند و با ۱ کلیک ثبت کند.
   - **مسدودسازی قطعی رمز پویا (OTP):** پیامک‌های حاوی رمز پویا، کد تایید یا پیام‌های شخصی طبق پروتکل حریم خصوصی سیمرغ مطلقاً خوانده یا ذخیره نمی‌شوند.

3. **🎨 لوگو و نشان کاملاً دل‌بخواه (Customizable Logo):**
   - کاربر می‌تواند با کلیک روی لوگو یا از بخش تنظیمات:
     - تصویر لوگوی دلخواه خود را مستقیماً از حافظه گوشی (PNG, JPG, SVG) آپلود کند.
     - از بین نشان‌های آماده (سیمرغ اصیل 🦅، الماس 💎، تاج 👑، زیتون 🌿، سکه 🪙، سپر 🛡️) انتخاب کند.
     - عنوان برنامه را به دلخواه خود تغییر دهد.

4. **⏰ هشدار زنگ بیدارباش و ارسال اعلان روی صفحه قفل (`AlarmManager` بومی):**
   - تنظیم خودکار زنگ بیدارباش دقیق و اعلان روی صفحه برای کارهای زمان‌دار و سررسید قبوض و بدهی‌ها.
   - دکمه‌های تعویق و توقف زنگ و بازتنظیم خودکار پس از روشن شدن گوشی (`BootRescheduleReceiver`).

5. **🌐 دوزبانه بودن کامل (فارسی راست‌به‌چپ ⇄ انگلیسی چپ‌به‌راست):**
   - جابه‌جایی آنی با دکمه اختصاصی در نوار بالا بدون نیاز به بارگذاری مجدد.

6. **🔒 معماری ۱۰۰٪ آفلاین و بدون هوش مصنوعی ابری:**
   - تمام داده‌ها منحصراً روی حافظه خصوصی دستگاه کاربر ذخیره می‌شوند و هیچ ارتباط خارجی برقرار نمی‌شود.

## 📂 ساختار فایل‌های پروژه (`simorgh-lifeos-android`)

```text
simorgh-lifeos-android/
├── build.gradle.kts                      # SDK 35 + بدون هیچ وابستگی ابری/هوش مصنوعی
├── settings.gradle.kts
├── gradle.properties
└── app/
    ├── build.gradle.kts
    ├── proguard-rules.pro
    └── src/main/
        ├── AndroidManifest.xml           # مجوزهای پیامک بانکی، زنگ دقیق و اعلان صفحه
        ├── java/ir/simorgh/lifeos/
        │   ├── MainActivity.kt           # اکتیویتی اصلی و هماهنگ‌کننده پل بومی
        │   ├── bridge/SimorghJsBridge.kt # پل ارتباطی کامل کاتلین و جاوااسکریپت (SimorghNative)
        │   ├── sms/BankSmsParser.kt      # موتور استخراج مبالغ، ریال به تومان و فیلتر OTP
        │   ├── sms/BankSmsReceiver.kt    # دریافت پیامک و فیلتر سرشماره‌های مجاز کاربر
        │   ├── alarm/SimorghAlarmScheduler.kt # زمان‌بندی زنگ دقیق
        │   ├── alarm/SimorghAlarmReceiver.kt  # پخش زنگ و اعلان صفحه قفل
        │   ├── alarm/BootRescheduleReceiver.kt# بازگردانی زنگ‌ها بعد از ری‌استارت گوشی
        │   ├── security/BiometricVault.kt     # حسگر اثر انگشت اختیاری
        │   └── widget/SimorghWidgetProvider.kt# ویجت موجودی صفحه اصلی اندروید
        ├── res/                          # منابع دوزبانه FA/EN، آیکون و ویجت
        └── assets/www/                   # رابط کاربری لوکس تیتانیوم بدون شلوغی
            ├── index.html
            ├── local-vault.js            # دیتابیس محلی و فیلتر مخاطبان مجاز
            ├── bank-sms-ai.js            # پنل فیلتر سرشماره و ثبت دستی پیامک
            ├── i18n-simorgh.js           # مترجم دوزبانه + شخصی‌سازی کامل لوگو
            ├── v2.js / v3.js / v4.js     # موتور صفحات، دخل‌وخرج، عادت‌ها و کارها
            └── v2.css / v3.css / v4.css  # استایل لوکس تیتانیوم
```

## 🛠️ راهنمای باز کردن در Android Studio

1. نرم‌افزار **Android Studio** را باز کنید.
2. گزینه **Open** را انتخاب کرده و مسیر این پوشه را مشخص کنید.
3. با تکمیل هماهنگ‌سازی گریدل (`JDK 17`)، پروژه آماده اجرا روی شبیه‌ساز یا گوشی واقعی شماست.
